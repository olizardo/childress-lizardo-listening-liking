# Plan: Diagnose and Optimize `overclaiming_report.qmd` Rendering Workflow

## Context & Objectives
Rendering `overclaiming_report.qmd` involves computing intensive statistical operations, including fixed-effects multinomial logistic regressions (`nnet::multinom`), two-way cluster-robust variance-covariance estimation (`sandwich::vcovCL`), and marginal predictions (`marginaleffects::predictions`). When recomputed from scratch on every run without caching or artifact reuse, rendering can cause significant latency or memory bottlenecks. Furthermore, several redundant computations and heading structures in the document can be streamlined.

## Proposed Strategy & Implementation Steps

### 1. Enable Caching & Smart Artifact Loading
- Check for existing pre-computed objects (`model_fixed.rds`, `robust_vcov_twoway.rds`, `pred_marg.rds`, `model_mblogit.rds`, `model_mblogit_intercepts.rds`).
- Refactor heavy model estimation chunks (`multinomial-model`, `clustered-se`, `marginal-effects-plot`) to either:
  - Load pre-computed `.rds` files if available (with fallback to fitting if absent), or
  - Enable Quarto chunk-level caching (`#| cache: true`) to avoid re-fitting models and recalculating cluster-robust matrices on every compile.

### 2. Clean Up Redundant Calculations & Structure in `overclaiming_report.qmd`
- **Fix duplicate headings**: Remove extraneous header `### True Engagement Across Different Genres (AME)` appearing right above `### Overclaiming Across Different Genres (Random Coefficients)`.
- **Deduplicate Demographic Ratios**: In `overclaim-prestige-correlation`, reuse `pref_df` or avoid redundant calculations of `pref_col` and `pref_black` already computed in earlier chunks.
- **Ensure Clean Output Formatting**: Verify all tables (`gt`) and ggplot figures render cleanly without unnecessary warnings or message pollution by standardizing chunk options (`#| warning: false`, `#| message: false`).

### 3. Verify & Test End-to-End Rendering
- Render `overclaiming_report.qmd` using `quarto render overclaiming_report.qmd` and verify execution speed and generated HTML output (`overclaiming_report.html`).
- Ensure all plots in `Plots/` and tables in `Tabs/` are properly produced and embedded.
